# How Pixel works

Pixel works from definitions. When a product is added, its definition is checked, given a version
number and a checksum, and stored so it can never change underneath the people using it. Every
question and every request is answered by one engine reading that pinned version: the engine finds
what was meant, checks that the person is allowed to see the records involved, and answers from
them. Wording comes from Pixel itself, so a definition can describe a product but cannot put words
in the assistant's mouth.
